## Dataset

* **Dataset:** PlantVillage
* **Source:** Kaggle
* **Classes:** Potato Early Blight, Potato Late Blight, Potato Healthy
* **Task:** Potato leaf disease classification
* **Dataset link:** [PlantVillage Dataset](https://www.kaggle.com/datasets/arjuntejaswi/plant-village)

> Only the potato leaf images from the PlantVillage dataset were used in this project.
> The dataset is not included in this repository due to its size.
